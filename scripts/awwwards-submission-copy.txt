SHORT DESCRIPTION (max 185 characters — paste into Description field)
Senior mobile engineer portfolio as an interactive iPhone: lock screen, app folders for work and experience, in-phone case studies, and a Games arcade—React, TypeScript, Framer Motion.

LONGER PROJECT STORY (for extended fields / your notes)
The site replaces a scroll-heavy résumé with a familiar phone metaphor. Visitors swipe up from a lock screen, browse company and project folders like iOS apps, open case studies inside the device chrome, and reach contact via the dock. Built solo with React 18, TypeScript, React Router, and Framer Motion; OG and Awwwards assets are generated via Puppeteer at build time.
