SHORT DESCRIPTION (max 185 characters — paste into Description field)
Senior mobile engineer portfolio as an interactive iPhone: lock screen, Experience & Projects, in-phone About Me, theme Settings, case studies—React, TypeScript, Framer Motion.

LONGER PROJECT STORY (for extended fields / your notes)
The site replaces a scroll-heavy resume with a familiar phone metaphor. Visitors swipe up from a lock screen, use the location and stats widgets, open the Experience hub and individual role stories, browse web projects as home-screen apps, and read case studies inside the device chrome. Settings swaps phone themes (saved locally); Open Source opens from the stats widget. The dock exposes Mail, LinkedIn, GitHub, and About Me (résumé, stack, education). Built solo with React 18, TypeScript, React Router, and Framer Motion; OG and Awwwards cover assets are generated via Puppeteer at build time.
